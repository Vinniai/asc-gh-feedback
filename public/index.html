Questions

How does the App Store Connect side work?

You upload a team API key (.p8, App Manager role) once. We use it to create the TestFlight webhook for your app via Apple's official API and to fetch full submission details when feedback arrives. Keys are encrypted at rest and never leave the processing path — the same trust model used by CI providers like Bitrise and Codemagic.

What lands in the GitHub issue?

The tester's comment, every screenshot, the crash log (for crashes), and a device table: model, OS, app version and build, locale, timezone, connection type, battery, free disk, and app uptime. Plus labels you configure — defaults are testflight-feedback and needs-triage.

What exactly does the AI triage do?

It reads the issue against your repository: identifies the screen or feature involved, traces the likely root cause with file/line references, posts an analysis comment, sets a type label and a P0–P3 priority, dedupes against existing issues — and on the Autofix plan, opens a branch and PR when the diagnosis is confident.

Can I self-host it?

Yes. The single-tenant core is open source and deploys to Cloudflare Workers, Vercel, or any Node 20+ host — with an agent skill included that walks through the whole setup. The hosted product adds multi-tenancy, encrypted key management, the delivery dashboard, and managed AI triage.

Is my tester data safe?

Webhooks are verified with a per-tenant HMAC secret before anything is processed. Credentials are AES-256-GCM encrypted at rest. Offboarding deletes the Apple webhook and purges stored data.
